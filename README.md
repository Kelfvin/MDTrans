# MDTrans Demo

This demo runs the official `mineru` CLI from an async Python subprocess, then translates the generated Markdown into Simplified Chinese with LangChain and an OpenAI-compatible chat model.

## Requirements

- Python environment from this repo
- Official `mineru` package installed in the repo environment
- Runtime requirements needed by the selected MinerU backend
- `OPENAI_API_KEY` exported in the shell before running
- `config.toml` with the LLM base URL and model name

## Config

`config.toml` is required and must contain:

```toml
[llm]
base_url = "https://api.openai.com/v1"
model = "gpt-4.1-mini"
context_window = 64000
```

`OPENAI_API_KEY` is intentionally not read from `config.toml`. Keep it in the environment, for example through your existing `env.sh`.

## Run

```bash
source env.sh
uv run mdtrans /path/to/input.pdf /path/to/output-dir
```

The script:

1. accepts the source PDF path as the first positional argument
2. accepts the output directory as the second positional argument
3. runs `mineru -p <selected-pdf> -o <output-dir> -b hybrid-auto-engine`
4. discovers the generated Markdown files under the chosen output directory
5. writes translated Chinese copies as `*.zh.md` beside the original Markdown files

After installation or within the uv environment, the command is:

```bash
mdtrans <source.pdf> <output-dir>
```

## Outputs

- Official MinerU output directory: the directory passed as the second CLI argument
- Original Markdown files generated by MinerU
- Chinese Markdown copies named `*.zh.md`

The program exits immediately if:

- `OPENAI_API_KEY` is not set
- `config.toml` is missing
- `[llm]` is missing from `config.toml`
- `llm.base_url` or `llm.model` is empty
- `llm.context_window` is missing or invalid

If the `mineru` subprocess fails, the script raises an error with the command and `stderr` output.

## Token Tool

To estimate document length with a general OpenAI tokenizer:

```bash
python tools/token_length.py path/to/file.md
```

This tool reads a single UTF-8 text file and prints character count, line count, and token count using `cl100k_base`.
